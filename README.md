# ECG 12-lead simulator (Godot 4.7, мобильный) — v18

Векторный симулятор: His-Пуркинье (сегментная активация, эмерджентная ширина QRS),
3D-диполь, препараты с дозами, вероятность патологии, T по Вилсону, кардиостимулятор
(VVI/AAI/DDD/BiV + неисправности), желудочковые экстрасистолы, нагрузочная проба.

## Открыть
Godot 4.7 → Import → project.godot → F5.

## Что нового в v18 — Ревизия
- **Единые клинические пороги.** Все пороги (ЧСС 100/60, ST ±1.0 мм, QRS 120 мс, QTc 460,
  PR 200, K/Ca, T) вынесены в один блок `const THR` в `ecg_model.gd`. `classify`,
  `pathology_probabilities`, `_normal_conf`, `wellbeing`, `electrolyte_dx`, `_st_description`
  используют его — дубли и расхождения устранены. Центры сигмоид дифф-диагноза совмещены
  с порогами (на пороге ровно 50% уверенности): PR 208→200, QTc 465→460, брадикардия 58→60.
- **Производительность `_render_one`.** Вместо цикла по всем ударам на каждый отсчёт —
  скользящие окна активных событий (P/QRS/спайки отсортированы по времени). Результат
  бит-в-бит идентичен (проверено в Python); сложность O(отсчёты + удары).
- **Электрическая ось — поведение задокументировано** (см. ниже).

## Новые клинические сценарии (v18)
- **Желудочковые экстрасистолы (ЖЭ).** Параметр `pvc_rate` (ЖЭ/мин) вставляет
  преждевременные широкие комплексы без предшествующего P с компенсаторной паузой
  (очаг = `pvc_focus`). Автоматически появляются **на пике нагрузочной пробы**
  (чаще при коронарном стенозе) и угасают в восстановлении. Доступны и вручную
  (Монитор → «Желудочковые экстрасистолы»).
- **Неисправности ЭКС** (`pace_fault` для VVI):
  - *Потеря захвата* — спайк есть, QRS за ним следует не всегда.
  - *Undersensing* — ЭКС не видит собственный ритм и стимулирует асинхронно;
    спайк вне рефрактерного периода захватывает, внутри — нет (конкуренция ритмов).
- **Бивентрикулярная стимуляция (BiV/CRT).** Режим `pace_biv`: активация из двух
  очагов (ПЖ-верхушка + ЛЖ-боковая) через `_activation_foci` → **слитный узкий QRS**
  (qeff ~126 мс против ~196 мс при одиночной VVI-стимуляции — проверено), два спайка,
  R в aVR, верхняя ось — клинические маркеры CRT.
- **Инверсия T в правых грудных при ПНПГ.** Добавлен вторичный *дискордантный* зубец T
  (вектор кзади, +Z), противоположный терминальным силам ПЖ → T инвертирован в V1–V3,
  лимб/V6 остаются положительными, норма не затронута (отдельная ветка для `block==1`).
  Чистое увеличение плотности/веса сетки ПЖ оказалось недостаточным (проверено в
  Python — глобальный вес ломал латеральный T), поэтому использован физиологичный
  механизм вторичной реполяризации.

- **Вторичный T при ПЛНПГ — уточнён.** (При перепроверке выяснилось, что направление
  T при ПЛНПГ и так было дискордантным — ранее это скрыл артефакт измерения, окно
  попадало в хвост широкого QRS.) Но первичный T по Вилсону давал лишь мелкую
  фиксированную инверсию (~2 мм). Теперь вторичный T при ПЛНПГ задан явно:
  дискордантный (против главного вектора ЛЖ) и **пропорционален амплитуде QRS** —
  глубокая инверсия в I/aVL/V5-V6 при высоком R, положительный T в V1-V3
  (проверено по всем осям, масштабируется с r_amp).

## Трепетание предсердий (v18.4)
- Новый ритм `aflutter`: предсердия ~300/мин, непрерывные **пилообразные волны F**
  (асимметричный «зуб»: медленный спад ~78% цикла, резкий подъём ~22% — без изолинии,
  проходят и сквозь QRS-T). Вектор F кверху → отрицательная пила в II/III/aVF,
  дискретные положительные F в V1, низкие в I.
- Проведение **N:1 выводится из ЧСС** (`ratio = round(300/ЧСС)`, 1..6): ЧСС 150 → 2:1,
  ЧСС 75 → 4:1. Пресеты 2:1 и 4:1. Распознаётся в заключении и дифф-диагнозе.

## Задний ИМ, гипертрофии с перегрузкой, AV-блокады 2 ст. (v18.3)
- **Задний ИМ** (зеркало V1-V2): `st_z>0` (повреждение кзади) → депрессия ST в V1-V2;
  патологический Q (вектор некроза кпереди) → высокий R в V1-V2; T положительный.
  Всё эмерджентно из существующих механизмов (st_vec + патологический Q).
- **Гипертрофия с перегрузкой (strain)** (`strain`): вторичная реполяризация ПРОТИВ
  главного вектора — косонисходящая депрессия ST + асимметричная инверсия T в
  отведениях с высоким R. ГЛЖ → I/aVL/V5-V6; ГПЖ → V1-V3.
- **ГПЖ: доминантный R в V1** (`rv_boost`): усиление передне-правых сил → R/S>1 в V1,
  правая ось, инверсия T в правых грудных.
- **AV-блокада 2 ст. Мобитц I (Венкебах)**: PR прогрессивно удлиняется (+55 мс/удар),
  пока QRS не выпадает (P без QRS), затем цикл 4:3 повторяется — групповое сокращение.
- **AV-блокада 2 ст. Мобитц II**: PR постоянный, периодически внезапно выпадает QRS (3:2).
- Все распознаются в дифф-диагнозе / заключении.

## ЭКГ-синдромы и передний ИМ (v18.2)
- **Передний ИМ → QS.** Некроз гасит R в направлении повреждённой стенки: передняя
  R-компонента масштабируется на `1 − 1.1·align·(q_amp/3.5)`, где `align` — проекция
  направления передней R на ST-вектор. Для переднего ИМ align высок → потеря R (QS в
  V1-V3); для нижнего мал → грудные не страдают.
- **WPW** (`delta_amp` + короткий PR): дельта-волна — медленный смазанный начальный
  подъём QRS (предвозбуждение).
- **Wellens** (`t_post`): глубокая симметричная инверсия T в V2-V4 без подъёма ST
  (критический стеноз ПМЖВ) — задний T-вектор.
- **Ранняя реполяризация** (`j_wave`): зазубрина J-волны на конце QRS + вогнутый
  подъём ST, нижне-боковые.
- **Перикардит** (`pr_dep` + диффузный ST): вогнутый подъём ST в большинстве отведений
  + депрессия PR-сегмента (Ta-волна), реципрокно — депрессия ST и элевация PR в aVR.
- **Бругада тип 1** (`t_post` + ST к V1): «свод» (coved) подъём ST в V1-V2 + инверсия T.
- Синдромы распознаются в дифф-диагнозе (вкладка «Анализ») по характерным признакам.

## Форма ST/T, P, Q (v18.1)
- **Форма сегмента ST** (`st_shape`): +1 — выпуклый «надгробный» подъём STEMI, −1 —
  корытообразная депрессия (дигоксин). Кривизна ∝ уровню ST, поэтому реципрокные
  отведения автоматически зеркалят форму. STEMI-пресеты → +1, дигоксин → −1.
- **Патологический Q инфаркта**: вектор некроза направлен ПРОТИВ ST-вектора, поэтому
  Q появляется в тех же отведениях, что и подъём ST — территориально верно (нижний →
  II/III/aVF, передний → V1-V4). Эмерджентно из `st_vec`, только при норм. проведении.
- **U-волна** (`u_amp`, выражена при гипокалиемии): после T, конкордантна, малой
  амплитуды; при гипоK сливается с уплощённым T.
- **Заострение T** (`t_sharp`, гиперкалиемия): сужает T → высокий «шатровый» зубец.
- **Морфология P** (`p_morph`): *pulmonale* — высокий заострённый P (ГПП); *mitrale* —
  широкий двугорбый P с задней терминальной частью → двухфазный P в V1 (ГЛП).
- Новые пресеты: P-mitrale, P-pulmonale; STEMI-пресеты обновлены (Q + выпуклый ST).

## Реализм сигнала (v18.1)
- **Дыхательная синусовая аритмия** (`resp_arr`, по умолч. 0.06): RR удлиняется на
  выдохе / укорачивается на вдохе (~15 дых/мин) — ритм «живой», не метрономный.
- **Дрейф изолинии** (`baseline_wander`) и **сетевая наводка 50 Гц** (`mains_noise`) —
  опц. артефакты ТОЛЬКО на бегущем мониторе; сетка 12 отведений и анализ остаются
  чистыми (`_add_artifacts` в `generate_monitor`, не в `generate_all`).
- **Дискордантный T при стимуляции.** ЭКС из ПЖ (VVI) и BiV — широкие комплексы с
  поздней активацией ЛЖ, поэтому теперь дают вторичный дискордантный T (как ПЛНПГ):
  T противоположен главному вектору QRS (проверено: VVI QRS+/T−, BiV QRS−/T+).
- Тумблеры — вкладка «Монитор» → «Реализм сигнала».

## Прогрессия R V1→V6 и калибровка оси (v18.1)
Добавлена передне-левая «переходная» R-компонента для нормального проведения (`kind=="n"`):
`_u(Vector3(0.70, 0.10, -0.70)) * r_amp*0.5`, тайминг у пика главного вектора. Она решает
сразу две задачи (проверено в Python):
- **Грудные:** физиологичная прогрессия R V1→V6 с переходной зоной **V3-V4** (rS в V1-V2 →
  R-доминантность к V4-V6), S убывает. Раньше R почти не рос (~2 мм по всем грудным).
- **Ось:** левая фронтальная часть компенсирует S в I от ПЖ-сил, и измеренная ось теперь
  ≈ параметру: `qrs_axis` −30/0/30/60/90° → измеренная −27/−3/28/**59**/90° (было до 80-103°).

Геометрический принцип: лимб-отведения имеют z=0, поэтому задняя (−Z) часть компоненты
правит только грудные, а фронтальная (X,Y) — ось; блокады/эктопия используют свою форму
(компонента к ним не добавляется), поэтому морфология ПНПГ/ПЛНПГ не затронута.

## Реакция АД на нагрузку
- Систолическое/диастолическое АД меняется по ступеням и показывается в сводке и на тренд-графике (зелёная линия САД).
- **Норма**: САД плавно растёт (125 → ~195 на пике).
- **Выраженный стеноз → экзерционная гипотензия**: САД нарастает до середины нагрузки, затем ПАДАЕТ на пике (≈142 → 121), пока ЧСС продолжает расти — грозный признак тяжёлой ишемии/дисфункции ЛЖ. Заключение помечает «патологическая реакция АД».
- Падение АД проходит и в самочувствие (вкладка «Анализ» показывает АД текущей ступени).

## Автопрогон нагрузочной пробы
- Кнопка **«Запустить пробу»**: таймер сам ведёт по ступеням (~2 с на ступень), и весь движок обновляется — монитор ускоряется, депрессия ST и реакция АД появляются на пике, заключение идёт следом. «Остановить» в любой момент; ручной сдвиг этапа тоже останавливает автопрогон.

## Нагрузочная проба (вкладка «Проба»)
- Сценарий-контроллер: ступени нагрузки (Покой → Ступени 1-4 → Пик → Восстановление) гонят ЧСС от покоя к целевой (0.85·(220−возраст)).
- **Возраст** задаёт целевую ЧСС.
- **Коронарный стеноз** (Нет/Умеренный/Выраженный): при нагрузке выше ишемического порога появляется ишемическая **депрессия ST** в боковых/нижних отведениях с реципрокной элевацией в aVR (вектор субэндокардиальной ишемии к aVR — клинический паттерн), глубже при большем стенозе и ЧСС; в восстановлении угасает.
- **Ползунок этапа** — двигаешь по ступеням, и весь движок (бегущий монитор, 12 отведений, диагноз, самочувствие) показывает текущее состояние нагрузки в реальном времени.
- **Тренд-график**: ЧСС и депрессия ST по ступеням, с порогом 1 мм и маркером текущего этапа.
- **Заключение пробы**: отрицательная / сомнительная / положительная (по макс. депрессии ST, накапливается по мере нагрузки).
